# New Radhaswami Mobile Gallery 📱✨
> **India's Premier Luxury Smartphone Destination • Authorized Flagship Showroom & Operations Terminal**

---

## 🌟 Overview
**New Radhaswami Mobile Gallery** is a high-performance, full-stack luxury storefront and operations terminal built with **React 18**, **TypeScript**, **Tailwind CSS**, **Three.js / React Three Fiber**, and **Express / Node.js**.

Designed with a high-contrast palette, fluid interactive physics, React Bits Pro animated components, a 3D Titanium Smartphone stage, and an enterprise-grade Owner Master Suite and Staff Operations Terminal.

---

## 🚀 Key Features

### 🛒 Customer Storefront
- **3D Interactive Smartphone Showcase**: Real-time 3D rendered titanium models with interactive orbit gimbal controls.
- **Buttery Smooth Page Navigation**: Seamless transitions between the Curated Showroom and the Dedicated 28+ SKU Catalog Shop page.
- **Genuine 0% No-Cost EMI Calculator**: Instant price sync for any device with tenure breakdown (3–24 months) and one-click WhatsApp Concierge inquiry.
- **Strict Voucher System**: Live backend coupon validation with instant rejection for expired/deleted codes.
- **Customer Account & Tracking**: Direct order tracking, SMS carrier authorization, and isolated cart persistence.
- **Responsive Mobile Dock**: Bottom navigation bar with zero occlusion and thumb-friendly controls.

### 🛡️ Owner Master Suite & Staff Operations
- **Root Inventory Terminal**: Live hardware SKU manager with direct multi-image file upload (base64 and server persistence), out-of-stock toggles, pricing edits, and JSON backup exports.
- **Executive Financials**: Real-time gross revenue, operating margin, average order value, and live transaction stream.
- **Promotions & Coupon Studio**: Dynamic voucher generation (percentage or flat discount, minimum cart value, activation toggles).
- **Broadcast Announcement Studio**: Global banner and popup broadcast manager with countdown timers, customizable themes, and preview modes.
- **0% EMI Rule Engine**: Configure minimum cart thresholds, bank partner availability, and interest subsidies.
- **POS Showroom Invoicing & Quotations**: Generate client quotations and branded showroom invoices with GST calculations.
- **Device Service & Repair Desk**: Intake tracking, IMEI registration, technician assignments, and progress tracking.
- **Root Security**: Double-layer PIN credentials for Owner Suite and Staff Terminal with audit logging.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide React

## 💻 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- Git

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/jeeban22222323-cell/NEW-RADHASWAMI-MOBILE-GALLERY.git
   cd NEW-RADHASWAMI-MOBILE-GALLERY
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the backend server**:
   ```bash
   npm run server
   ```
   *Runs on `http://localhost:5000`*

4. **Start the frontend development server**:
   ```bash
   npm run dev
   ```
   *Runs on `http://localhost:3000`*

5. **Build for production**:
   ```bash
   npm run build
   ```
